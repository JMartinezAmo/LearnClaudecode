# Curso de Vibe Coding con Claude Code

> Versión: Claude Code 1.0.x (Diciembre 2024)

## Qué es Vibe Coding

Vibe coding es programar describiendo lo que quieres en lugar de escribir cada línea. Le dices a Claude Code qué necesitas, él genera el código, tú validas y ajustas.

No es magia ni reemplazo del pensamiento crítico. Es una herramienta que amplifica tu capacidad de construir software. Sigues siendo tú quien decide qué construir, cómo estructurarlo y cuándo algo está bien.

La diferencia con programar "a mano": en lugar de traducir ideas a sintaxis, te enfocas en comunicar intención. Claude traduce. Tú supervisas.

## Para quién es este curso

Para personas que quieren construir software con Claude Code pero no saben por dónde empezar. No necesitas saber programar, pero sí necesitas curiosidad y disposición a experimentar.

## Qué NO es este curso

No es un curso de programación tradicional. No te enseñaremos JavaScript, Python ni ningún lenguaje específico. Aprenderás a comunicarte con Claude Code para que él escriba el código por ti.

## Requisitos

- **Cuenta de GitHub** - Para gestionar tu código
- **Plan Pro de Claude** - Necesario para Claude Code
- **Terminal básica** - Saber abrir una terminal y ejecutar comandos
- **Ganas de experimentar** - Lo más importante
